Espera a «Sin conexión listo» antes de cortar la red. Conserva la misma URL y navegador. Los permisos de XR y passthrough deben probarse en las Quest en modo avión; el sistema puede desalojar la caché.

A · Link público (recomendado)

  1. Con internet, abre el link público en Meta Quest Browser.
  2. Carga el juego y esta página; espera la instalación completa.
  3. Inicia una misión y elige VR o MR si aparecen. Luego prueba modo avión.

B · USB y adb reverse

Requiere modo desarrollador de Quest, depuración USB autorizada y ADB instalado. No se configura desde el juego. 

python -m http.server 8000 --directory simulador
adb devices
adb reverse tcp:8000 tcp:8000

En el navegador de las gafas abre http://localhost:8000. Loopback se considera contexto seguro; comprueba WebXR en ese navegador. localhost en las gafas solo llega al computador si el túnel USB está activo. Al desconectar el cable deja de funcionar el túnel.

C · Red local HTTPS sin internet

Prepara antes del salón un servidor HTTPS en el computador y un certificado cuyo emisor confíen las gafas. Todos los equipos deben estar en la misma red Wi-Fi local, sin aislamiento de clientes. No basta HTTP por IP: WebXR y service workers exigen contexto seguro.

La guía README contiene comandos con mkcert y el servidor HTTPS incluido. Instalar la CA en las gafas depende de la administración del dispositivo: comprueba confianza real antes de la clase. Si no se puede instalar, usa A o B. No ignores advertencias de certificado.
